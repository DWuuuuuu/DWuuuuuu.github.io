# Jeremy D. Wu’s portfolio

Open `index.html` in a browser or serve this folder with a static web server. GitHub Pages can publish the repository root directly. The publication index is in `publications.html`. The comparison controls and the Epigram solutions use native HTML and CSS.

The visual design adapts [Maria](https://github.com/xocothemes/maria). Its MIT notice and the licenses for the locally hosted Hanken Grotesk and Instrument Serif fonts are in `assets/`. The Epigram image comes from the product’s public solutions walkthrough.

Pair each new project with a visual that shows what someone can do or learn from it. Use a product screenshot for a tool, a labeled figure for a result, or a worked example for a method. Store the asset locally, provide alt text, and label simulated data and illustrative examples.
