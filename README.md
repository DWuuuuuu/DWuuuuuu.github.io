# DWuuuuuu.github.io

Personal site for Jeremy D. Wu, served at <https://DWuuuuuu.github.io>.

Static HTML and CSS. No framework, no build step, no JavaScript.

- `index.html` is the page
- `styles.css` holds all styling, with a dark theme via `prefers-color-scheme`
- `favicon.svg` is the tab icon

To preview locally, open `index.html` in a browser.
